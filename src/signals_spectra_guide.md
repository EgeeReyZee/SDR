# Сигналы и спектры: учебник простым языком

Материал построен по вашим лекциям (ряд Фурье, преобразование Фурье, цепи) и практикам (коэффициенты ряда, ортогональность, свертка, ПФ, RC-цепь). Читайте по порядку: каждый раздел опирается на предыдущий.

---

## Карта всего курса

1. **Периодический сигнал** → раскладываем в сумму гармоник (ряд Фурье).
2. **Спектр** = «рецепт»: сколько какой гармоники (амплитуда и фаза).
3. **Непериодический сигнал** → периодов нет, спектр становится непрерывным (преобразование Фурье).
4. **Свертка** = как цепь превращает входной сигнал в выходной во времени.
5. **Частотная характеристика** = то же самое, но в частотной области (просто умножение).

Главная мысль: любой сигнал можно описать двумя способами, во времени `s(t)` и по частоте `s(jω)`. Переходить между ними помогает преобразование Фурье. Во времени цепь делает **свертку**, по частоте цепь делает **умножение**.

## 1. Ряд Фурье

### Идея
Возьмите любой периодический сигнал с периодом T. Его можно собрать, сложив синусоиды с частотами:

- основная частота `ω₁ = 2π/T` (первая гармоника),
- `2ω₁`, `3ω₁`, ... (высшие гармоники),
- плюс постоянная составляющая (среднее значение).

Аналогия: звук аккорда. Аккорд это сумма нот, а ряд Фурье это «разложение аккорда на ноты».

### Формулы (синусно-косинусная форма)

```
s(t) = a₀/2 + Σ ( aₖ·cos(kω₁t) + bₖ·sin(kω₁t) ),  k = 1, 2, 3, ...

aₖ = (2/T) ∫₀ᵀ s(t)·cos(kω₁t) dt
bₖ = (2/T) ∫₀ᵀ s(t)·sin(kω₁t) dt
a₀/2 = (1/T) ∫₀ᵀ s(t) dt     ← среднее значение сигнала
```

**Как понимать интеграл.** Мы умножаем сигнал на «пробную» синусоиду и усредняем. Если сигнал содержит такую частоту, произведение в среднем положительное, и коэффициент большой. Если не содержит, плюсы и минусы взаимно гасятся, и коэффициент около нуля. Это и есть «вычисление гармоники» на слайдах с графиками: сигнал × косинус → интеграл произведения → число.

### Амплитуда и фаза (косинусная форма)

Пару `aₖ, bₖ` удобно заменить на одну косинусу со сдвигом:

```
Aₖ = √(aₖ² + bₖ²)        — амплитуда k-й гармоники
φₖ = −arctg(bₖ / aₖ)     — начальная фаза
s(t) = a₀/2 + Σ Aₖ·cos(kω₁t + φₖ)
```

### Полезные правила симметрии

| Сигнал | Что в ряду |
|---|---|
| Чётный, `s(−t) = s(t)` | только косинусы (все `bₖ = 0`) |
| Нечётный, `s(−t) = −s(t)` | только синусы (все `aₖ = 0`) |

Интеграл всегда берется **по одному периоду**.

## 2. Спектр периодического сигнала

**Спектр** это график коэффициентов ряда Фурье. Нужны два графика:

- **амплитудный спектр**: высота линии `Aₖ` на частоте `kω₁`;
- **фазовый спектр**: значение `φₖ` на той же частоте.

У периодического сигнала спектр **линейчатый (дискретный)**: только отдельные линии на частотах `0, ω₁, 2ω₁, ...`.

Примеры из лекции:
- **Постоянное напряжение**: одна линия на частоте 0.
- **Одна синусоида**: одна линия на её частоте; задержка сигнала меняет только фазу.

---

## 3. Комплексная форма ряда Фурье

Из формулы Эйлера:

```
cos α = (e^{jα} + e^{−jα}) / 2
sin α = (e^{jα} − e^{−jα}) / (2j)
```

ряд можно записать короче:

```
s(t) = Σ cₖ · e^{j k ω₁ t},   k от −∞ до +∞
cₖ = (1/T) ∫₀ᵀ s(t) · e^{−j k ω₁ t} dt
|cₖ| = |c₋ₖ| = Aₖ / 2
```

Замечание про знак: в слайде в формуле для `cₖ` показан плюс в показателе. Стандартная запись (и та, при которой формулы согласованы) использует минус, как выше. Если на экзамене попросят формулу «как на слайде», сверьтесь с лектором.

### «Отрицательные частоты»
В комплексной форме появляются частоты `−kω₁`. Реально их **не существует**: это следствие формулы Эйлера, ведь один косинус превращается в две экспоненты, на `+ω` и на `−ω`. Поэтому модуль `|cₖ| = Aₖ/2`: амплитуда делится пополам между двумя частотами.

## 4. Периодическая последовательность прямоугольных импульсов

Параметры:
- `Um` амплитуда импульса,
- `τ` длительность импульса,
- `T` период,
- **скважность** `q = T/τ` (во сколько раз период больше импульса).

Результаты (импульс симметричен относительно нуля, поэтому сигнал чётный):

```
Постоянная составляющая:  U₀ = Um·τ/T = Um/q
bₖ = 0
aₖ = (2Um/q) · sin(πk/q) / (πk/q)
Aₖ = |aₖ|
φₖ = 0 или ±π (знак зависит от знака aₖ)
```

Функция `sin(x)/x` называется **sinc**. Она даёт «огибающую» с лепестками.

### Что от чего зависит

| Величина | От чего зависит |
|---|---|
| Расстояние между линиями | `f₁ = 1/T` (только период) |
| Ширина главного лепестка (до первого нуля) | `1/τ` (только длительность) |
| Число линий в одном лепестке | `q = T/τ` |
| Гармоники с нулевой амплитудой | номера `k = q, 2q, 3q, ...` |

### Разбор трёх случаев из практики (письменное задание)

| Случай | q = T/τ | f₁ = 1/T | Первый ноль 1/τ | U₀ (в долях Um) | Нулевые гармоники |
|---|---|---|---|---|---|
| T = 0.1 с, τ = 0.05 с | 2 | 10 Гц | 20 Гц | 0.5 | k = 2, 4, 6... |
| T = 0.1 с, τ = 0.025 с | 4 | 10 Гц | 40 Гц | 0.25 | k = 4, 8... |
| T = 0.2 с, τ = 0.05 с | 4 | 5 Гц | 20 Гц | 0.25 | k = 4, 8... |

Выводы для сравнения:
- Второй случай против первого: период тот же (линии на тех же местах), а импульс короче, поэтому спектр шире и амплитуды ниже.
- Третий случай против первого: импульс тот же (первый ноль на 20 Гц), а период больше, поэтому линии гуще (5 Гц вместо 10 Гц).

Подставьте числа в `Aₖ = (2Um/q)·|sin(πk/q)/(πk/q)|` для `k = 1...6` и нарисуйте линии. Для q = 2: `A₁ = (2Um/2)·sin(π/2)/(π/2) = 0.637·Um`, `A₂ = 0`, `A₃ = 0.212·Um`.

## 5. Преобразование Фурье (непериодические сигналы)

### Идея
Что, если период T → ∞? Тогда сигнал становится одиночным импульсом. Первая гармоника `ω₁ = 2π/T` стремится к нулю, линии спектра сближаются и сливаются в **непрерывную кривую**. Амплитуды отдельных линий уходят в ноль, поэтому описывают не амплитуду, а **спектральную плотность** (размерность В/Гц, «сколько сигнала приходится на 1 Гц»).

### Пара преобразований

```
Прямое:   s(jω) = ∫ s(t) · e^{−jωt} dt        (от −∞ до +∞)
Обратное: s(t)  = (1/2π) ∫ s(jω) · e^{jωt} dω
```

Результат комплексный: `s(jω) = s(ω)·e^{jφ(ω)}`. Здесь `s(ω)` это модуль (спектральная плотность амплитуд), `φ(ω)` фаза.

Связь с рядом: для периодического сигнала `cₖ` можно получить из спектра одного периода, взятого на частотах `kω₁` (в слайде записано с множителем `2/T`, это зависит от того, комплексная или косинусная амплитуда; для комплексной формы множитель `1/T`).

### Спектр прямоугольного импульса

Для импульса высоты `Um` и длительности `τ` (от −τ/2 до τ/2):

```
s(jω) = Um · τ · sin(ωτ/2) / (ωτ/2)
```

- Значение в нуле: `Um·τ` (площадь импульса).
- Нули при `ωτ/2 = πn`, то есть на частотах `f = n/τ`.
- **Короче импульс → спектр шире. Длиннее импульс → спектр уже.**
- Если считать шириной спектра первый ноль, `Δf = 1/τ`, то `Δf · τ = 1`: произведение ширины спектра на длительность примерно постоянно.

Примеры из лекции: для импульса 2 мс первый ноль на 0.5 кГц, для 4 мс на 0.25 кГц, для 1 мс на 1 кГц.

### Теоремы о спектрах (свойства ПФ)

| Теорема | Что утверждает | Что видно на практике |
|---|---|---|
| **Сложение** | Спектр суммы = сумма спектров | линейность |
| **Запаздывание** | Сдвиг сигнала на `τ₀`: спектр × `e^{−jωτ₀}` | модуль **не меняется**, фаза получает линейную добавку `−ωτ₀` |
| **Смещение спектра** | Спектр, сдвинутый на `ω₀`, соответствует `s(t)·e^{jω₀t}` (в слайде знак записан иначе, суть та же) | умножение на `cos(ω₀t)` переносит спектр на `±ω₀`, амплитуда вдвое меньше |
| **Свертка** | Спектр свертки = произведение спектров | см. раздел 6 |

### Радиоимпульс
Радиоимпульс это отрезок гармонического колебания с огибающей, например прямоугольной: `s(t) = U₀·cos(ω₀t)` на `0 ≤ t ≤ τ`. Его спектр это **та же sinc-кривая, но с центром на частоте `ω₀`** (и зеркальная копия на `−ω₀`), с высотой вдвое меньше. Это прямое следствие теоремы смещения спектра, и именно её проверяет последняя часть практики по ПФ.

## 6. Свертка

### Что это
Если цепь линейная и не меняется со временем, то отклик на любой вход вычисляется через **импульсную характеристику** `h(t)` (реакцию цепи на очень короткий импульс):

```
y(t) = ∫ s(τ) · h(t − τ) dτ
```

### Как считать по шагам (так делается практика)
1. Заменить переменную `t` на `τ` у обеих функций.
2. **Отразить** вторую функцию: `s₁(−τ)`.
3. **Сдвинуть** её на `t`: `s₁(t − τ)`. Для большего `t` график едет вправо.
4. **Перемножить** `s₂(τ) · s₁(t − τ)`.
5. **Проинтегрировать** по τ (площадь под произведением). Это одно число, значение результата в момент `t`.
6. Повторить для каждого `t` и построить график `y(t)`.

### Что ожидать
- Два прямоугольных импульса (длительности 1 и 2 с) дают **трапецию**. Её длина равна сумме длительностей (3 с), а плоский участок равен разности (1 с).
- Прямоугольный импульс и гармоника дают «сглаженную» синусоиду (скользящее усреднение), амплитуда зависит от соотношения длительности и периода.
- Результат отличен от нуля только там, где функции перекрываются.

### Связь с Фурье (раздел 1.4 практики)
`ПФ{s₁ * s₂} = s₁(jω) · s₂(jω)`. Проверка: посчитать оба ПФ численно, перемножить, и сравнить с ПФ свертки. Графики модулей должны совпасть (с небольшой погрешностью из-за шага).

## 7. Частотная характеристика цепи

### Определения
Подаём на вход гармонику `U₁cos(ωt + φ₁)`, на выходе получаем `U₂cos(ωt + φ₂)` (частота та же!). Тогда:

- **КЧХ**: `H(jω) = (комплексная амплитуда выхода) / (комплексная амплитуда входа)`.
- **АЧХ** (модуль): `|H(jω)| = U₂/U₁`, во сколько раз цепь изменила амплитуду.
- **ФЧХ** (аргумент): `φ(ω) = φ₂ − φ₁`, на сколько цепь сдвинула фазу.

`h(t)` и `H(jω)` связаны преобразованием Фурье: `H(jω) = ∫ h(t) e^{−jωt} dt`.

### RC-цепь (ФНЧ)

```
h(t) = (1/RC) · e^{−t/RC}
H(jω) = 1 / (1 + jωRC)
|H(jω)| = 1 / √(1 + (ωRC)²)       ← АЧХ
φ(ω)   = −arctg(ωRC)               ← ФЧХ
```

Что это значит:
- На низких частотах `|H| ≈ 1`: сигнал проходит почти без изменений.
- На высоких частотах `|H| → 0`: подавляется (фильтр низких частот).
- Фаза всегда отрицательная: выход **отстаёт** от входа, от 0 до −90°.
- Постоянная времени `RC` (0.001 до 0.01 с по заданию) задаёт «границу»: при `ω = 1/RC` получаем `|H| = 0.707`, `φ = −45°`.

### Как найти выход на одной частоте (раздел 1.3)
1. Выберите частоту `ω`.
2. Вычислите `H(jω)`: модуль `M = |H|` и фазу `φ`.
3. Вход: `s₁(t) = A·cos(ωt)`.
4. Выход: `s₂(t) = A·M·cos(ωt + φ)`.
5. Нарисуйте оба на одном графике. Выход меньше и сдвинут вправо.

Пример из лекции: при `ω = 200π` коэффициент около 0.45, сдвиг `−0.35π`. При `ω = 1000π` коэффициент около 0.1, сдвиг `−0.47π`. Чем выше частота, тем сильнее подавление и ближе сдвиг к `−π/2`.

## 8. Практики с кодом (Python)

Общие импорты:

```python
import numpy as np
import matplotlib.pyplot as plt
```

### 8.1 Коэффициенты ряда гармоники

```python
f = 5; T = 1/f
Ts = 0.0001                       # мелкий шаг
t = np.arange(0, T, Ts)           # ровно ОДИН период
s = 2*np.cos(2*np.pi*f*t + 0)     # A=2, начальная фаза 0

a, b, A, phi = [], [], [], []
for n in range(5):                # n = 0..4
    an = 2/T*np.sum(s*np.cos(2*np.pi*n*f*t))*Ts
    bn = 2/T*np.sum(s*np.sin(2*np.pi*n*f*t))*Ts
    a.append(an); b.append(bn)
    A.append(np.hypot(an, bn))
    phi.append(-np.arctan2(bn, an))
```

Ожидание для `A = 2` и фазы 0: `a₁ = 2`, остальные около 0. При другой фазе `a₁ = 2cosφ`, `b₁ = −2sinφ`, но `A₁ = 2` не меняется. Меняется только фаза.

Важно: интегрировать по **целому числу периодов**. В примере из задания `t = np.arange(-0.1, 0.1, Ts)` берёт 1 период только при подходящих параметрах, иначе появляется ошибка. Для `n = 0` используйте `1/T*sum*Ts` (это `a₀/2`).

### 8.2 Ряд для прямоугольного сигнала и синтез

```python
T, tau, Um = 0.1, 0.05, 1
Ts = 1e-4
t = np.arange(-T/2, T/2, Ts)
s = np.where(np.abs(t) <= tau/2, Um, 0.0)

N = 6
a0 = 1/T*np.sum(s)*Ts                     # это a0/2
w1 = 2*np.pi/T
a = [2/T*np.sum(s*np.cos(k*w1*t))*Ts for k in range(1, N+1)]
b = [2/T*np.sum(s*np.sin(k*w1*t))*Ts for k in range(1, N+1)]

# синтез: сумма первых K гармоник
for K in (2, 4, 6):
    y = a0 + sum(a[k-1]*np.cos(k*w1*t) + b[k-1]*np.sin(k*w1*t)
                 for k in range(1, K+1))
    plt.plot(t, y, label=f'K={K}')
plt.plot(t, s, 'k--'); plt.legend(); plt.show()
```

Чем больше гармоник, тем ближе сумма к прямоугольнику. Около скачков остаются «выбросы» (явление Гиббса).

### 8.3 Ортогональность

```python
T = 1; f1 = 1/T; Ts = 1e-4
t = np.arange(0, T, Ts)
s1 = np.sin(2*np.pi*f1*t)
for n in range(1, 6):
    sn = np.sin(2*np.pi*n*f1*t)
    print(n, np.sum(s1*sn)*Ts)       # ≈ 0 для n≠1, ≈ T/2 для n=1
```

- Для `n = k` интеграл равен `T/2` (не ноль, это «энергия»).
- Если брать **неполный период** или **частоту не кратную `f₁`**, интеграл **перестаёт быть нулём**. Эти проверки и просит выполнить задание.
- Комплексный случай: `s_n = np.exp(1j*2*np.pi*n*f1*t)`. Для комплексных сигналов ортогональность проверяется как `∫ s_k · conj(s_n) dt = 0` при `k ≠ n` (с сопряжением). Если буквально перемножать без сопряжения, ноль получится при `k + n ≠ 0`, поэтому для отрицательных индексов учитывайте разницу.

### 8.4 Свертка численно (интервал -1..4, шаг 0.05)

```python
dt = 0.01
tau = np.arange(-5, 5, dt)
s1 = lambda x: ((x >= 0) & (x < 1)).astype(float)   # импульс 1 с
s2 = lambda x: ((x >= 0) & (x < 2)).astype(float)   # импульс 2 с

ts = np.arange(-1, 4, 0.05)
y = [np.sum(s2(tau)*s1(ts_i - tau))*dt for ts_i in ts]
plt.plot(ts, y); plt.show()           # трапеция, максимум 1

# для проверки:
y2 = np.convolve(s1(ts_), s2(ts_), 'full') * dt   # если сигналы заданы на общей сетке
```

Для картинок по шагам: постройте `s1(-tau)`, `s1(t0 - tau)` для `t0 = -1, 0, 2`, произведение `s2(tau)*s1(t0 - tau)`, и закрасьте площадь (`plt.fill_between`).

### 8.5 Преобразование Фурье численно

```python
tau0 = 2
dt = 0.001
t = np.arange(-5, 5, dt)
s = np.where(np.abs(t) <= tau0/2, 1.0, 0.0)

f = np.linspace(0, 3/tau0, 300)       # (0 ... 3/τ)
S = np.array([np.sum(s*np.exp(-1j*2*np.pi*fi*t))*dt for fi in f])

plt.subplot(211); plt.plot(f, np.abs(S));   plt.title('Модуль')
plt.subplot(212); plt.plot(f, np.angle(S)); plt.title('Фаза')
```

Проверки:
- **Длительность**: при `τ` вдвое меньше нули уходят вдвое дальше (на `1/τ`).
- **Задержка**: `s = np.where((t >= 0) & (t <= tau0), 1, 0)`; модуль остаётся прежним, фаза получает линейный наклон.
- **Модуляция**: умножьте на `np.cos(2*np.pi*f0*t)` и считайте спектр около `f0` (диапазон частот сдвиньте, например `f0 ± 3/τ`).
- Аналитическая проверка: `|S(0)| = Um·τ` (для τ = 2 с это 2).

### 8.6 RC-цепь

```python
RC = 0.005
Ts = 1e-5
t = np.arange(0, 0.05, Ts)
h = (1/RC)*np.exp(-t/RC)

f0 = 1000                           # частота входа, Гц
s1 = np.sin(2*np.pi*f0*t)
y = np.convolve(s1, h)[:len(t)]*Ts   # выход через свертку
plt.plot(t, s1, t, y); plt.show()

# АЧХ и ФЧХ
f = np.linspace(0.01, 3/RC, 500)
w = 2*np.pi*f
H = 1/(1 + 1j*w*RC)
plt.subplot(211); plt.plot(f, np.abs(H))
plt.subplot(212); plt.plot(f, np.angle(H))
```

Проверка согласованности: выход, полученный сверткой (после установления, то есть спустя несколько `RC`), должен совпасть по амплитуде и фазе с `|H(jω₀)|·sin(ω₀t + φ(ω₀))`.

Замечание: в задании «интервал частот (0 … 3/RC) Гц»: если ось в герцах, то `ω = 2πf`. Следите, где используется `f`, а где `ω`.

## 9. Шпаргалка

| Что нужно | Формула / ответ |
|---|---|
| Основная частота | `ω₁ = 2π/T`, `f₁ = 1/T` |
| Постоянная составляющая | `a₀/2 = (1/T)∫s dt` |
| Амплитуда k-й гармоники | `Aₖ = √(aₖ² + bₖ²)` |
| Фаза | `φₖ = −arctg(bₖ/aₖ)` |
| Комплексный коэффициент | `cₖ = (1/T)∫s·e^{−jkω₁t}dt`, `\|cₖ\| = Aₖ/2` |
| Скважность | `q = T/τ` |
| Спектр прямоугольной последовательности | `Aₖ = (2Um/q)·\|sin(πk/q)/(πk/q)\|` |
| Нули спектра последовательности | `k = q, 2q, ...` |
| ПФ прямоугольного импульса | `Um·τ·sinc(ωτ/2)`, нули на `f = n/τ` |
| Ширина × длительность | `Δf·τ ≈ 1` |
| Задержка на `τ₀` | спектр × `e^{−jωτ₀}`, модуль не меняется |
| Умножение на `cos ω₀t` | спектр сдвигается на `±ω₀`, амплитуда ÷ 2 |
| Свертка | `ПФ(s₁*s₂) = s₁(jω)·s₂(jω)` |
| RC: КЧХ | `H = 1/(1 + jωRC)` |
| RC: АЧХ / ФЧХ | `1/√(1+(ωRC)²)` / `−arctg(ωRC)` |
| Выход цепи на гармонике | `A·\|H\|·cos(ωt + φ₁ + φ(ω))` |
